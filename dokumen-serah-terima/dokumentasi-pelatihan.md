# B. TUJUAN DAN SASARAN PESERTA

Membekali pengurus desa dan pemilik UMKM agar dapat memakai dan memperbarui Website Katalog UMKM Desa Sadomas secara mandiri setelah program KKM berakhir.

- **Pengurus Desa / Karang Taruna** -- mampu menambah, mengubah, dan menghapus data lewat `admin.html`.
- **Pemilik UMKM mitra** -- mampu memakai `toko-saya.html` untuk melihat statistik dan memasang promo tokonya sendiri.
- **Warga umum (opsional)** -- mengenal cara mencari dan memesan produk lewat situs/aplikasi.
