# APK Katalog UMKM Sadomas

Proyek Trusted Web Activity untuk situs:

https://1leafsrain.github.io/katalog-umkm-sadomas/

## Membuka di Android Studio

1. Buka folder `android-twa` sebagai project.
2. Tunggu Gradle Sync selesai.
3. Pilih emulator atau perangkat Android.
4. Klik Run untuk uji coba.
5. Pilih `Build > Build APK(s)` untuk membuat APK debug.

Package ID: `id.sadomas.katalog`

Untuk rilis Play Store, buat signing key sendiri dan pilih `Build > Generate Signed Bundle / APK`.
